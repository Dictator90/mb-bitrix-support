# Changelog

## Unreleased

- **`FileService` (DI):** экземплярный сервис, контракт `MB\Bitrix\Contracts\File\FileServiceContract`; в контейнере `app('file.service')` и тот же singleton по классу контракта; алиас `save()` → `saveFile()`; `FileService::method()` через `__callStatic` делегирует в `resolve()`; провайдер `MB\Bitrix\File\ServiceProvider`; классы `File\Image\*` принимают опционально `FileServiceContract` или используют `FileService::resolve()`.
- **`FileService` (D7):** мутации `b_file` через `FileTable::add` / `update` / `delete`; события `OnMakeFileArray` / `OnGetFileSRC` через `Bitrix\Main\Event`; единый `Loader::getDocumentRoot()`; валидация имён и расширений без `CBXVirtualIo` / глобальных `GetFileName` / `IsFileUnsafe`; транслит через `Bitrix\Main\Text\Transliterator` при наличии класса; квота — тонкие вызовы `CDiskQuota` с `@internal`; кеш строк файла — приватный `FileService::$fileDataCache`; `getFilesData` возвращает `null` для отсутствующих ID; трейт `RememberCachable::__callStatic('remember')` возвращает значение.
- **Config / namespace gaps (run `bitrix-core-namespace-api-gaps_01`):** `ConfigManager::get` uses `Entity::create()`; `ConfigLocator` targets `MB\Bitrix\Config\Entity`; `UseOptions` uses `Str::substr` (fixes bad `Str::substring` calls); `Application::buildWithParameters` gains working `resolveAliasName` / `getConcreteBinding` via container reflection; `Foundation\ServiceProvider` types `$app` as `Application` and fixes `pathsToPublish` when both provider and group are null; `Module\Entity::getConfig` PHPDoc cleaned; PHPStan covers `src/Config`, `src/Foundation`, `src/Module` with Bitrix stubs in `scripts/dev/bitrix-phpstan-stubs.php`; docs: README namespace policy, `docs/SUPPORTED.md` Config rows, `docs/smoke-config.md`.
- **DI / Laravel-like (no Illuminate):** `MB\Bitrix\Contracts\Config\Repository` + `Config\ArrayRepository`; `config()` helper and `Support\Facades\Config`; `module()` helper; `setBasePath()` loads `{basePath}/config/*.php`; `Support\Facade::clearResolvedInstances()` / `swap()` for tests; `MB\Bitrix\Contracts\Support\Renderable` replaces `illuminate/contracts`; removed `illuminate/contracts` from Composer requirements.
- **Docs:** `docs/laravel-parity.md`, `docs/examples/kernel-bootstrap.md`; stubs `scripts/dev/bitrix-app-minimal.php` for tests.
- **Module / container (post code-review):** `Module\Entity::getConfigClass()` now reflects `fillConfig()` / `ConfigLocator`; `getLibPath(): ?string` aligned with contract; callers guard null lib path. `Application::registerModule()` binds `{id}:module` with constructor param `id`; `{id}:migration` resolves to `MigrationFacade` built from the module entity.
- **Autoload:** Composer now registers `MB\\Core\\` alongside `MB\\Bitrix\\`; admin settings tree lives under `src/Settings/` for `MB\Core\Settings\*`.
- **`app()`:** Added package helper (see `src/Support/helpers.php`) mapping to `Foundation\Application::getInstance()`.
- **Module:** `Module\Entity::getMigrationFacade()` implemented; `fillConfig` fallback class fixed; `ModuleContainer` + `Application::container()` for per-module services.
- **Migration:** `Migration\Entities\File` / `Storage` namespaces aligned to `MB\Bitrix\Migration\Entities`; `Storage` migration uses new `StorageEntityManager` and `Migration\Facades\Storage` for ORM table sync; `Facade` uses `Contracts\Migration\Entity` for interface checks.
- **Migration facade:** `up()` / `down()` now delegate to `upAll()` / `downAll()` (`Contracts\Migration\Facade`); `upAll()` / `downAll()` still omit **agent** aggregation (intentionally commented — documented in `docs/migrations.md`).
- **EntityView:** `MenuAction` and `Parameters\Filter::getDefault()` completed with safe defaults.
- **Quality:** PHPUnit + PHPStan scaffolding; `SqlHelper` unit tests with minimal Bitrix DB stubs.
- **Docs:** `docs/SUPPORTED.md`, root `README.md`, package name corrected in `docs/README.md`.
